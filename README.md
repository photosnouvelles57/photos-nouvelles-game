# photos-nouvelles-game

Jeu 3D web mobile: vous incarnez un loup qui doit attraper le chaperon rouge dans une forêt de nuit enchantée.

## Lancer

Ouvrez `pn-game-pixi.html` dans un navigateur moderne (WebGL2 / mobile compatible).
Si besoin, lancez un mini serveur local:

```bash
python3 -m http.server 8080
```

Puis ouvrez `http://localhost:8080/pn-game-pixi.html`.

## Contrôles

- **Mobile**: joystick gauche pour se déplacer, bouton **Sprint** pour accélérer.
- **Clavier**: `WASD` ou flèches, `Shift` pour sprinter.
